# cart/game — Interactive game cartridges

Games that showcase the LLM-as-CPU pattern: structured input, LLM reasoning, structured output. Zero hardware requirements, maximum didactic value.

| Cartridge | Description |
|---|---|
| [`tetris`](tetris/full.md) | Turn-based Tetris. Methods: `move({action})`, `observe`, `reset`. The LLM plays by observing the board and choosing moves. |
